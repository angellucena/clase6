# 🎵 Concerts Week — Agenda Semanal de Música en Vivo

**Concerts Week** es una plataforma web desarrollada para consultar la cartelera de conciertos, festivales y recitales en vivo de la semana. Ofrece una experiencia visual moderna estilo *nightlife* con paleta neón, componentes interactivos y diseño 100% responsivo para móviles, tablets y escritorios.

---

## 🔗 Enlaces del Proyecto

* **Repositorio Público GitHub:** `https://github.com/angellucena/clase6`
* **Sitio Desplegado en Vivo (GitHub Pages):** `https://angellucena.github.io/clase6/`

---

## 🛠️ Tecnologías y Librerías Utilizadas

* **HTML5 Semántico:** Jerarquía estructurada (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<figure>`, `<figcaption>`, `<footer>`).
* **CSS3 Personalizado:** Paleta de colores en código HEX/RGB, estados interactivos (`:hover`, `:focus-visible`, `:active`), transiciones suaves y reseteo de modelo de caja.
* **Bootstrap 5 (v5.3.3 via CDN):** Sistema de grillas responsivas, **Navbar con menú hamburguesa responsivo** en todas las páginas y componentes **Carousel** en la portada y la galería.
* **Google Fonts:** Tipografías *Outfit* (encabezados) e *Inter* (cuerpo de texto).
* **Git & GitHub:** Control de versiones con commits semánticos y despliegue continuo mediante GitHub Pages.

---

## 📱 Páginas Completamente Adaptadas (Mobile & Desktop)

1. **`index.html` (Inicio):** Carrusel de héroe cinematográfico panorámico (*Lollapalooza 2027*, *Foo Fighters*, *Somos Música*) y agenda destacada.
2. **`pages/conciertos.html` (Cartelera):** Grilla responsiva con afiches de conciertos verticales completos (3:4) para *Lollapalooza Argentina*, *Foo Fighters* y *BTS*.
3. **`pages/galeria.html` (Galería):** Galería fotográfica interactiva con componente Carousel de Bootstrap en alta definición.
4. **`pages/nosotros.html` & `pages/contacto.html`:** Secciones de información del proyecto e interfaz de formulario estilizado.
